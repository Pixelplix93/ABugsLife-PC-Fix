# A Bug's Life PC Fix

<img width="1410" height="1116" alt="BugFix" src="https://github.com/user-attachments/assets/a711df08-2495-49bd-acb5-1a7adb9b4259" />


**This fix removes the game's dependency on drive `D:`, allowing it to run without the original CD or a disc image mounted specifically as `D:`. It also improves compatibility with modern versions of Windows and forces Hardware Mode.**


## Supported Version

A Bug's Life PC — English (US) version

## Features

* Removes the game's dependency on drive `D:`
* Allows the game to run without the original CD or a mounted disc image
* Improves compatibility with modern Windows systems
* Forces Hardware Mode and skips the renderer selection screen
* Includes dgVoodoo for improved fullscreen support, scaling, and compatibility


## Download

The fix is available in the **Releases** section.

The archive contains:

* `bugs.exe`
* `32.dll`
* dgVoodoo
* A README with installation instructions
